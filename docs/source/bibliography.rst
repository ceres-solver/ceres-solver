============
Bibliography
============

Background Reading
==================

For a short, informative introduction to non-linear least squares, we
recommend the booklet by [Madsen]_. For a general introduction to
non-linear optimization, we recommend [NocedalWright]_. [Bjorck]_
remains the seminal reference on least squares problems.
[TrefethenBau]_ is our favorite text on introductory numerical linear
algebra. [Triggs]_ provides a thorough treatment of the bundle
adjustment problem.
